# Roulette of Legends

League of Legends roulette: a random role and champion, solo or with friends, tracked in the LoL client all the way to the result.

## Download

Both apps are on the [releases](https://github.com/Raktos1030/Roulette-of-Legends/releases/latest) page:

| | Windows | Mac (Apple Silicon) |
|---|---|---|
| **Roulette of Legends Lite**: the roulette, linked to LoL | `Roulette-of-Legends-Lite-Setup.exe` | `Roulette-of-Legends-Lite-mac.dmg` |
| **Roulette of Legends**: the full version | `Roulette-of-Legends-Setup.exe` | coming soon |

Windows: run the installer. Mac: open the .dmg and drag the app into Applications; on first launch, System Settings › Privacy & Security › "Open Anyway".

New versions install from the app itself: a bar shows up with an **Update** button, and your history and settings are kept.

The apps are available in French and English.

## The two apps

| | Lite | Full |
|---|:---:|:---:|
| Solo and group roulette (up to 5 players), chaos mode | ✓ | ✓ |
| Favorites (roles and champions) | ✓ | ✓ |
| Roll tracked in the client: autofill, bans or a taken champion detected | ✓ | ✓ |
| Game history, results and LP | ✓ | ✓ |
| A guide for every champion in every role | | ✓ |
| Runes, summoner spells and item set imported into LoL | | ✓ |
| In-game overlay: guide, stats, gold difference, skill to level up on the HUD | | ✓ |
| Game page: both teams and their ranks | | ✓ |

The apps read the LoL client and never play for you: no picks, bans, lock-ins or chat. The only writes (full version, optional) are your rune page, summoner spells and an item set, once your champion is locked in.

Each launch sends one anonymous count (edition, version, Windows or Mac), with no cookie or identifier; it can be turned off in Settings. The website counts its visits the same way.

## From source

Python 3.11:

```
pip install -r requirements.txt
python roulette_lol.py
```

- `python roulette_lol.py --check`: checks that every champion + role combo has its guide.
- `python packaging/build.py full|lite`: builds an app and its archive in `_release/`.
- `site/`: the roulette as a static website, regenerated by `python site/build_site.py`.
